# Skrivi Snakk 0.3.2 — Test release

A clearer dictation interface, consistent with Skrivi Lytt.

- A short first-run introduction and prominent guidance for dictating into other applications.
- Current shortcuts shown on the main screen; a separate, cancellable shortcut capture dialog.
- Settings that fit smaller windows; scrolling over controls no longer changes their values.
- Whisper model names and a table showing model size, availability and active state.
- Consistent Privacy/About screens and simpler installer licence information.

Use **Skrivi-Snakk-0.3.2-windows-x64-setup.exe** for normal installation. Quit the existing tray app first. Existing settings and model files are preserved. The ZIP is the portable alternative. The MSIX is for Microsoft Store submission; availability here does not imply Store certification.

These are the exact signed files approved after PC testing, built from 25283f0ef486e82508b7cf912dda7a5ccb0de854 in https://github.com/workavoidance/Skrivi-STT/actions/runs/35537489391. Signatures, checksums, automated tests and installer preservation checks passed.
