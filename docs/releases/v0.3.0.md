# Skrivi Snakk 0.3.0 — Test release

Skrivi Snakk is the speech-to-text app in the Skrivi family. Its orange microphone
complements the speaker in [Skrivi Lytt](https://github.com/workavoidance/Skrivi-TTS/releases/tag/v0.4.1).
Both apps use **Test release** while real-world testing continues; their version
numbers advance independently. This is not a claim of production or school approval.

## Downloads

- **Skrivi-v0.3.0-windows-x64-setup.exe**: normal Windows 11 x64 installer,
  signed and timestamped by Open Source Developer Jonathan Wright.
- **Skrivi-v0.3.0-windows-x64.zip**: portable app containing a signed executable.
- **Skrivi-v0.3.0-windows-x64.msix**: unsigned package for the maintainer to
  upload to Microsoft Partner Center, not the normal PC installer. Store review
  and publication are separate; the live Store listing may still be older.
- Matching `.sha256` files allow download verification.

## What changed

- Consistent Skrivi Snakk name and orange microphone across the app and installer.
- Companion Lytt link and shortcut guidance in Settings.
- Safe migration of shortcuts owned by Snakk; existing settings and downloaded
  models stay in place. Uninstall also preserves those user files.
- Signed app, installer and uninstaller, with installation, reinstall and
  signature checks on a disposable Windows runner before publication.

Keep **Right Ctrl** or **Left Ctrl + Windows** for dictation and **Ctrl + Alt +
Space** for Lytt. Avoid assigning Left Ctrl + Left Alt to dictation when using both.

Close the app before upgrading, install, then open **Skrivi Snakk** from Start.
The first speech-model download requires internet; dictation then runs locally.
Signing verifies the publisher but does not guarantee that SmartScreen will
never display a reputation warning. Please report problems without private text
or student information in [GitHub issues](https://github.com/workavoidance/Skrivi-STT/issues).
