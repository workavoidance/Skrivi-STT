Skrivi er foreløpig alfa-programvare for Windows 11.

Dette er appen som heter «Skrivi» i Microsoft Store og Start-menyen i dag.

Slik fungerer det

Snakk. Slipp. Fortsett.

1

Hold inne snarveien

Hold inne høyre Ctrl-tast der du allerede skriver.

2

Snakk naturlig

Skrivi lytter mens du snakker og behandler talen lokalt på maskinen.

3

Slipp og fortsett

Teksten skrives inn der markøren allerede står.

For elever

Når tankene går raskere enn tastaturet.

Skrivi er laget for elever som vet hva de vil si, men som synes det er vanskelig å få det ned som tekst. Det kan være særlig nyttig for elever med dysleksi.

Skrivi får elevens egne ord ned på siden. Det lager ikke svaret for dem.

Skrivi

Installer. Snakk. Skriv.

Skrivi v0.2 alpha er tilgjengelig for Windows 11. Ingen Python, konto eller administratorrettigheter er nødvendig.

  1. Installer fra Microsoft Store for den enkleste, signerte installasjonen og automatiske oppdateringer.
  2. Vil du heller bruke en vanlig installasjonsfil, kan du laste ned samme versjon fra GitHub.
  3. Start Skrivi fra Start-menyen. Første oppstart laster ned og kontrollerer talemodellen én gang.

GitHub-installasjonen er ikke kodesignert og kan utløse en SmartScreen-advarsel. Begge utgavene er bygget fra den åpne kildekoden. Skrivi er fortsatt alfa-programvare.
