# Product interface captures

Captured 21 September 2026 from the actual Qt widgets in published release tags:

- Snakk v0.3.2, source commit 25283f0: Settings window, General tab.
- Lytt v0.4.3, source commit bc84d5f: reader window, preview mode.

Each has Norwegian Bokmål and English captures. These are release-source UI
captures, not mockups or proof of installed-package validation. Captions make
that distinction explicit. Windows Segoe UI fonts; 820 × 900 logical pixels.
Qt offscreen rendering; separate disposable settings and data directories.
No microphone recording, global hotkey registration, model download, speech
synthesis or personal text. The Lytt reader is empty; model setup is not simulated.

Regenerate from the exact public release when its interface changes. Do not
silently reuse these to illustrate a newer interface or a different Store build.
